## 先看懂四类套餐：差价差在哪里

搬瓦工在售套餐分四大类，价格差距主要来自回程线路，配置反而不是决定因素。

- **Basic KVM（常规款）**：1Gbps 普通线路，机房多、可自由迁移，但回程没有 CN2 优化。$49.99/年起，适合预算优先、对速度不敏感的场景。
- **CN2 GIA-E（E-Commerce）**：2.5Gbps 起步的大带宽，回程走电信 CN2 GIA、移动 CMIN2、联通 AS10099/9929 高端线路，可在洛杉矶 DC6、DC9、日本软银、荷兰等多个机房间免费迁移。季付 $49.99 起，是销量最大的一档。

- **固定机房高端款**：香港、东京、大阪、新加坡 CN2 GIA，物理距离近、延迟低，但机房固定不可迁移，月付 $49.99 起。

4. 个人信息**如实填写**，国家选 China，省市按实际填。支付方式选 **Alipay**。
5. 勾选同意服务条款，点 **Complete Order** 提交订单。
6. 点 **Make payment**，页面跳到支付宝二维码，扫码付款。
7. 付款成功后一般会自动跳回搬瓦工网站；没跳转就等一会儿，再不行手动打开官网登录查看。

## 付款后：开通、KiwiVM 面板和 SSH 连接

付款后开通通常很快，IP 和 root 初始密码会发送到注册邮箱。登录搬瓦工后台，点 **My Services** 找到你刚买的实例，再点 **KiwiVM Control Panel** 进入控制面板，机房位置、IP、SSH 端口、运行状态都在这里看。

后续连接用 SSH：Linux/Mac 直接用终端 `ssh root@你的IP -p 端口`，Windows 可以用 Xshell、PuTTY 之类的工具，端口注意用面板里显示的端口（搬瓦工默认不是 22）。系统重装、快照、备份也都在 KiwiVM 里操作，支持 CentOS、Debian、Ubuntu、RockyLinux、AlmaLinux，也可以手动挂 ISO 安装。

GIA-E 和 KVM 常规款还支持在面板里一键迁移机房（Migrate to another DC），迁移不丢数据、不用重装系统。买了 GIA-E 之后想从 DC6 换到日本软银，或者反过来，都只是点几下的事。

## 下单前容易踩的坑

这几条都来自官方页面和真实教程里的注意事项，下单前过一遍能省不少麻烦：

- **注册和购买时不要挂代理**，地址如实填写。信息与 IP 归属地对不上，订单可能被判欺诈。
- **便宜套餐只有年付**。20G KVM、40G KVM 都没有月付档，想月付试水只能选 80G KVM（$19.99/月）及以上的型号，或者 GIA-E 的季付。
- **续费价与新购价一致**，不存在“首年特价、续费翻倍”的套路，年付的价格就是以后每年的价格。
- **流量超出按 $1/GB 计费**。跑大流量业务前先算好月用量，不够就升级套餐，别硬扛超额账单。
- **搬瓦工是严格自管服务**，没有保姆式工单支持，系统层面的问题要自己解决，官方管的是硬件和网络。

## 常见问题

**支持微信支付吗？** 支付宝、PayPal、信用卡是确定支持的；部分教程提到也支持微信付款，以你结账页实际显示的支付选项为准。

**有退款保障吗？** 有第三方攻略提到搬瓦工提供 30 天退款。这一条属于下单前值得自己在结账页条款里确认的事项，不同套餐和支付方式可能存在差异。

**IP 不可用了怎么办？** KVM 常规款和 GIA-E 可以通过面板迁移到其他机房，迁移后 IP 会更换；SLA 套餐自带每两周免费换 IP 一次的权益。固定机房高端款不可迁移，这是低延迟线路的代价之一。

**买哪个机房好？** GIA-E 系列不确定就选洛杉矶 DC6，之后随时可以在面板里换；联通用户可以试试日本软银 JPOS_1；欧洲业务选荷兰 EUNL_9。
